# 前端 UI 任务清单（详细版）

本清单仅覆盖前端 UI/交互层，不含后端业务逻辑实现。建议按优先级推进：路由 → 列表/详情 → 发布/订单 → 消息/个人中心 → 细节打磨。

---

## 1. 路由与导航（高优先级）
- [ ] 引入 React Router（替代 `src/App.tsx` 的 `currentPage` 切换）
  - [ ] `/` 首页（商品/分类）
  - [ ] `/category/:id` 分类页
  - [ ] `/item/:id` 商品详情
  - [ ] `/sell` 发布/卖出页（或弹窗入口）
  - [ ] `/buy` 买入页
  - [ ] `/cart` 购物车/订单页
  - [ ] `/donation` 捐赠入口
  - [ ] `/donation/form` 捐赠表单
  - [ ] `/donation/thanks` 捐赠完成页
  - [ ] `/profile` 个人中心
  - [ ] `/about` 关于
- [ ] 深链接与刷新恢复
  - [ ] 刷新页面时能保持在当前页
  - [ ] URL 参数与筛选/排序状态同步（可选）
- [ ] Header 导航与路由联动
  - [ ] 登录/注册入口与路由/弹窗配合
  - [ ] Buy/Sell/Donation 按钮跳转路由
  - [ ] 当前页高亮/状态提示
