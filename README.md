# DIC04-Circulink

Circulink 项目本地运行说明。

## 项目简介

这是一个基于 **Vite + React + TypeScript** 的前端项目。

## 环境要求

请先确保本机已安装：

- Node.js（建议 18+，推荐 20+）
- pnpm

可用下面命令检查版本：

```bash
node -v
pnpm -v
```

推荐启动流程

首次拉起项目，直接执行下面这组命令即可：

git clone git@github.com:404NotFound-Error/DIC04-Circulink.git
cd DIC04-Circulink
npm install -g pnpm
pnpm install
pnpm run dev
